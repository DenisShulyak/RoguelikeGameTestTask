# RoguelikeGame

Unity project using the Universal Render Pipeline (URP).

## Open the project

1. Clone this repository.
2. Install **Unity 6000.3.2f1** through Unity Hub.
3. In Unity Hub, add the repository root as a project and open it.
4. Wait for package restoration and asset import, then open `Assets/Scenes/SampleScene.unity`.

## Version control

- Commit `Assets/` with all associated `.meta` files, `Packages/` (including `packages-lock.json`), and `ProjectSettings/`.
- Unity is configured for **Visible Meta Files** and **Force Text** serialization.
- Generated caches, logs, builds, IDE files, and local Plastic SCM data are excluded by `.gitignore`.
- Keep `.meta` files with their assets when moving or renaming them to preserve references.
- Current assets are small; Git LFS is not required for this snapshot.
